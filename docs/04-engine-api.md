# 04 — Engine API

Status: Draft v0.1 · 2026-11-21

The engine API is the product. The shell, the CLI and (P1) MCP are clients of it. The OpenAPI document
generated by FastAPI is committed at `engine/openapi.json`. The shell's TypeScript client is generated
from it, and CI fails if the client is stale.

## Conventions

- **Base:** `http://127.0.0.1:<port>/api/v1`. WebSocket: `ws://127.0.0.1:<port>/api/v1/ws`.
- **Auth:** `Authorization: Bearer <token>` on every request, including the WS upgrade (as a header, or the `token` query parameter for clients that can't set headers). The token comes from the handshake or `engine.json`.
- **Errors:** RFC 9457 problem+json `{type, title, status, detail, code}` with stable `code`s: `missing_key`, `budget_exceeded`, `estimate_required`, `provider_error`, `rate_limited`, `not_found`, `invalid_rule`, `offline`.
- **Long work** returns `202` with a `job` id; progress arrives over WS as `job.progress`.
- **Money** is always `usd_estimate` as a decimal string, never a float.
- **IDs** are prefixed: `doc_`, `blk_`, `utt_`, `rule_`, `act_`, `rec_`, `job_`, `voice_` (voice IDs are `provider:model:voice`, e.g. `openai:gpt-4o-mini-tts:coral`).

## REST resources

### Documents

| Method | Path | Purpose |
|---|---|---|
| `POST` | `/documents` | Create from `{kind: file\|url\|text\|image\|html_blocks\|clipboard, ...}`; multipart for files. Returns `{document, estimate?}` |
| `GET` | `/documents` | Recents and search (`?q=` full text, `?limit=`) |
| `GET` | `/documents/{id}` | Metadata, progress, source kind, page count |
| `GET` | `/documents/{id}/blocks` | Typed blocks with anchors (paged) |
| `GET` | `/documents/{id}/script` | The speech plan: utterances with anchors, fidelity, and which rules acted on which spans (powers Script view and the speech diff) |
| `POST` | `/documents/{id}/regenerate` | Rebuild the plan (new Claude pass); estimate first |
| `PUT` | `/documents/{id}/settings` | Per-document voice, mode (Classic/AI Enhanced), pin offline |
| `DELETE` | `/documents/{id}` | Remove the document and its unpinned caches |

`html_blocks` is what the shell's page preload posts: `{url, title, blocks: [{id, type, text, dom_anchor}]}`.

### Playback (one transport)

| Method | Path | Body |
|---|---|---|
| `GET` | `/playback` | → `{state, document_id, utterance_id, offset_ms, speed, voice_id, time_left_s}` |
| `POST` | `/playback/play` | `{document_id?, from?: {block_id, char?} \| {page} \| {utterance_id}}` |
| `POST` | `/playback/pause` · `/resume` · `/stop` | — |
| `POST` | `/playback/skip` | `{unit: sentence\|paragraph\|heading\|seconds, count: ±n}` |
| `PUT` | `/playback/speed` | `{speed: 0.5–5.0}` |
| `PUT` | `/playback/voice` | `{voice_id, scope: document\|default}` |

### Voices

| Method | Path | Purpose |
|---|---|---|
| `GET` | `/voices` | All available voices `{id, provider, model, name, languages, styles, local, available, unavailable_reason?}` |
| `POST` | `/voices/{id}/preview` | Plays a cached sample (synthesized once per voice and style) |

### Rules and skills

| Method | Path | Purpose |
|---|---|---|
| `GET` | `/rules` | All rules with scope, tier, enabled, file path |
| `POST` | `/rules/proposals` | `{instruction, scope?, document_id?}` → a proposed rule file + speech diff on that document (no write) |
| `POST` | `/rules` | Save a rule (usually from a confirmed proposal) |
| `PATCH` | `/rules/{id}` · `DELETE` `/rules/{id}` | Edit (e.g. enable/disable) / delete |
| `GET` · `PUT` | `/rules/presets` | Preset toggles and `mode: classic\|ai_enhanced` (per scope) |
| `GET` · `POST` · `DELETE` | `/rules/lexicon` | Pronunciation entries |
| `GET` | `/skills` | Installed skills (P1) |

### Assistant

| Method | Path | Purpose |
|---|---|---|
| `POST` | `/assistant/turns` | `{text, recording_id?, context: {document_id?, selection?}}` → `{turn_id}`; the reply streams over WS |
| `POST` | `/actions/{id}/confirm` · `/cancel` | Resolve a pending action card |

### Usage

| Method | Path | Purpose |
|---|---|---|
| `GET` | `/usage/summary` | `?period=today\|week\|month&group_by=provider\|op\|document` → totals, breakdown, cache savings |
| `GET` | `/usage/ledger` | Raw rows, paged, filterable |
| `POST` | `/usage/estimate` | `{document_id \| source, voice_id?, mode?}` → `{usd_estimate, breakdown, assumptions}` |
| `GET` · `PUT` | `/usage/budget` | `{monthly_usd, warn_at: 0.8, hard_stop: true}` |

### Settings, keys, models, recordings

| Method | Path | Purpose |
|---|---|---|
| `GET` · `PATCH` | `/settings` | `settings.toml` as JSON (schema published in OpenAPI) |
| `PUT` | `/keys/{provider}` | Write-only `{key}` → test call → `{ok, provider, detail}`. No `GET` exists |
| `GET` | `/keys` | `{provider: configured\|missing\|invalid}` only |
| `GET` | `/models/local` | Local model catalog with installed state, size, RAM, hardware fit |
| `POST` · `DELETE` | `/models/local/{id}` | Install (→ job) / remove |
| `GET` | `/recordings/{id}` | Ogg/Opus audio of a user utterance or assistant reply |
| `GET` | `/health` | `{ok, version, uptime_s}` (still requires the token) |

## WebSocket protocol

One socket per client. Messages are JSON `{type, id?, ts, ...}`, except mic audio, which is sent as binary
frames (16-bit LE PCM, 16 kHz mono) between `mic.start` and `mic.stop`.

**Client → engine**

| type | Fields | Meaning |
|---|---|---|
| `mic.start` | `session_id`, `mode: push_to_talk\|auto` | Begin a recording/STT session |
| *(binary)* | PCM frames | Mic audio |
| `mic.stop` | `session_id` | End of utterance (push-to-talk release) |
| `command` | `text`, `source: typed\|spoken` | Submit to the fast-path parser, then the agent |
| `subscribe` | `topics: [...]` | Defaults to all |

**Engine → client**

| type | Fields | Meaning |
|---|---|---|
| `stt.partial` | `session_id`, `text` | Live transcript (replace in place) |
| `stt.final` | `session_id`, `text`, `recording_id` | Final transcript; recording stored |
| `assistant.delta` | `turn_id`, `text` | Streaming reply text |
| `assistant.action` | `turn_id`, `action_id`, `kind`, `summary`, `preview?` | Needs confirmation (rule diff, budget change, …) |
| `assistant.done` | `turn_id`, `reply_recording_id?` | Turn finished; reply audio available for replay |
| `playback.state` | transport snapshot | On every state change |
| `playback.word` | `document_id`, `utterance_id`, `anchor`, `fidelity` | Word/segment boundary for highlighting. `anchor` is one of `{block_id, char_start, char_end, bbox?}`, `{block_id, dom_anchor}`, or `{media_t0, media_t1}` |
| `usage.alert` | `level: warn\|stop`, `spent`, `budget` | Budget events |
| `job.progress` | `job_id`, `pct`, `label` | Downloads, long plans, exports |
| `error` | problem+json | Async failures |

## CLI

```
open-speech serve [--port 0] [--handshake stdout]
open-speech read <path|url|-> [--voice ID] [--speed 1.8] [--mode classic|ai] [--from-page N]
open-speech pause | resume | stop | status
open-speech skip [--sentence|--paragraph] [N]
open-speech voices [--provider P] [--lang L]
open-speech rules ls | add "<instruction>" [--site S] | rm <id>
open-speech usage [--today|--week|--month] [--by provider|op|document]
open-speech estimate <path|url>
open-speech models ls | install <id> | rm <id>
open-speech keys set <provider>        # prompts without echo
```

The CLI talks to a running engine through `engine.json`, or starts an ephemeral one. Output is
human-readable by default, with `--json` for scripts.

## MCP server (P1)

stdio transport (`open-speech mcp`). Tools are thin wrappers over `service/`:

| Tool | Purpose |
|---|---|
| `read_aloud` | `{source: path\|url\|text, voice?, speed?, mode?}` |
| `playback` | `{action: pause\|resume\|stop\|skip, ...}` |
| `where_am_i` | Current document, section, time left |
| `get_usage` | `{period, group_by}` |
| `estimate_cost` | `{source}` |
| `list_voices` | `{provider?, lang?}` |
| `add_rule` | `{instruction, scope}`. Returns the proposal; saving needs `confirm: true` |

## OpenAI-compatible facade (P1)

| Path | Behavior |
|---|---|
| `POST /v1/audio/speech` | `{model, voice, input, instructions?, response_format?, speed?}`. `model` may be any catalog voice id or an alias; rules (opt-in header `X-Open-Speech-Rules: classic\|ai`), cache and ledger apply |
| `POST /v1/audio/transcriptions` | Routed to the configured STT provider (cloud or local) |
| `GET /v1/models` · `GET /v1/audio/voices` | Catalog listing |

This makes Open Speech a drop-in local speech gateway for any tool that already speaks the OpenAI audio API.

## Versioning and compatibility

- `/api/v1` is stable within a major version. Additive changes only; breaking changes go to `/api/v2`.
- The WS event set is versioned with `{"type": "hello", "protocol": 1}` on connect.
- `engine/openapi.json` and `engine/ws-schema.json` are committed and diffed in CI.
